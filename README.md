# Футбольная секция «Высота»

## Описание
Сайт для футбольной секции с функционалом:
- Информационные страницы (о нас, контакты, расписание)
- Магазин мерча с корзиной
- Отзывы покупателей
- Запись на занятия
- Аренда манежа
- Абонементы в спортзал

## Технологии
- Backend: Python 3.14, Flask 3.1.3
- База данных: SQLite
- Frontend: HTML5, CSS3, JavaScript

## Запуск проекта
1. Установить Python 3.10+
2. Установить зависимости: `pip install -r backend/requirements.txt`
3. Создать файл `.env` на основе `.env.example`
4. Запустить сервер: `python backend/app.py`
5. Открыть в браузере: `http://localhost:5000`

## Быстрый запуск

### Windows (BAT-скрипты)
```bash
scripts\setup.bat      # Установка зависимостей
scripts\run.bat        # Запуск сервера
```
