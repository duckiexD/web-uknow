# RISK_REGISTER.md

## Реестр рисков безопасности и эксплуатации

| № | Риск | Причина | Вероятность | Влияние | Мера снижения |
|---|------|---------|-------------|---------|---------------|
| R-01 | Утечка секретов (.env) | Файл может случайно попасть в Git | Низкая | Высокое | .gitignore, .env.example, регулярная проверка |
| R-02 | Доступ к чужим данным | Нет проверки владельца ресурса | Низкая | Высокое | Добавлена валидация user_id, все запросы проверяют права |
| R-03 | Уязвимости в зависимостях | Старые версии библиотек | Низкая | Среднее | pip-audit, регулярное обновление |
| R-04 | Потеря данных БД | Нет автоматического бэкапа | Средняя | Высокое | Создан backup.bat, настроено ручное копирование |
| R-05 | Сервис не поднимается после сбоя | Нет проверки health | Низкая | Среднее | Docker restart policy, check_deploy.bat |
| R-06 | CORS настроен слишком широко | Допустим доступ с любых доменов | Низкая | Среднее | CORS ограничен конкретными доменами |
| R-07 | Отладка включена в production | DEBUG=True может раскрыть информацию | Низкая | Высокое | В .env.production DEBUG=False |
| R-08 | Нет HTTPS | Данные передаются в открытом виде | Низкая | Высокое | При деплое на VPS настроить Let's Encrypt |
| R-09 | SQLite блокировка при записи | Не подходит для высокой нагрузки | Низкая | Среднее | Запланирована замена на PostgreSQL |
